# لوحة القرار التنفيذية — جمعية إعمار المرافق

موقع لوحة تحكم تنفيذية لرئيس مجلس إدارة جمعية إعمار المرافق، مبني على بيانات الخطة التشغيلية الفعلية لعام 2026 (بطاقة أداء متوازن بأربعة أبعاد استراتيجية).

## المحتوى

- **نظرة عامة**: مؤشرات أداء رئيسية (عدد المبادرات، إجمالي الميزانية، متوسط نسبة التحقق، الوقت المنقضي من عمر الخطة) وملخص بطاقات لكل بُعد استراتيجي (بعد المستفيدين، البعد المالي، بعد العمليات الداخلية، بعد التعلم والنمو).
- **المبادرات والمشاريع**: جدول قابل للبحث والفلترة حسب البُعد الاستراتيجي، لكل المبادرات الـ17 مع الحالة والمؤشر والميزانية والمسؤول وحالة الدعم. الضغط على أي مبادرة يفتح وصفها التفصيلي.

## تشغيل الموقع محليًا

الموقع ثابت بالكامل (HTML/CSS/JS بدون أي اعتماديات خارجية)، يكفي فتحه مباشرة أو تشغيل خادم بسيط:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## مصدر البيانات: مزامنة حيّة مع Google Sheets

عند فتح الموقع (وعند الضغط على زر "تحديث")، يجيب `assets/js/sheet-sync.js` أحدث بيانات المبادرات
مباشرة من 4 تبويبات في شيت الخطة التشغيلية (بعد المستفيدين، البعد المالي، بعد العمليات الداخلية،
بعد التعلم والنمو) عبر روابط تصدير CSV مباشرة (`/export?format=csv`)، ويحوّلها لنفس شكل بيانات
المبادرات المستخدم في الموقع. تظهر شارة بجانب زر "تحديث" توضّح إذا كانت البيانات المعروضة حيّة من
الشيت أو آخر نسخة محفوظة (عند تعذّر الاتصال).

يُستخدم رابط التصدير المباشر بدل ميزة "نشر على الويب" لأن الأخيرة تأخذ لقطة قد تتجمّد ولا تتحدّث
تلقائيًا مع كل تعديل. رابط التصدير المباشر يقرأ محتوى الشيت الفعلي لحظيًا، لكنه يتطلب أن تكون
صلاحية مشاركة الشيت (زر Share الرئيسي، وليس Publish to web) مضبوطة على **"أي شخص لديه الرابط:
عارض" (Anyone with the link: Viewer)**.

معرّف الشيت (`SHEET_ID`) وقيم `SHEET_SOURCES` (gid لكل تبويب) معرّفة في أعلى `assets/js/sheet-sync.js`.
إذا احتجت ربط شيت آخر أو تبويبات إضافية، حدّثها هناك.

**ملاحظة حول عمود "المتبقي":** ملف الخطة التشغيلية المصدر يحتوي خطأ في معادلة "المتبقي" ضمن تبويب "بعد المستفيدين" (يعرض 0 رغم عدم الصرف). لذلك تحسب هذه اللوحة "المتبقي" دائمًا كـ (الميزانية − المصروف) بدل نسخه من الشيت مباشرة.

### النسخة الاحتياطية (fallback)

كل بيانات اللوحة موجودة أيضًا كنسخة احتياطية ثابتة في ملف واحد:

```
assets/js/data.js
```

تُستخدم هذه النسخة فقط إذا تعذّر الاتصال بالشيت (لا إنترنت، أو تغيّرت إعدادات النشر). يُستحسن
تحديثها بين حين وآخر يدويًا (نسخ آخر أرقام من الشيت) لتبقى نسخة احتياطية معقولة، رغم أن الموقع لا
يعتمد عليها طالما المزامنة الحيّة تعمل.

## النشر

الموقع ثابت بالكامل، يمكن نشره فورًا على أي من:
- GitHub Pages
- Netlify / Vercel (سحب المجلد مباشرة)
- أي استضافة تدعم ملفات HTML ثابتة

## هيكل الملفات

```
index.html              الصفحة الرئيسية (كل الأقسام)
assets/css/style.css    التنسيق (فاتح/داكن)
assets/js/data.js       البيانات القابلة للتعديل
assets/js/app.js        منطق اللوحة (التبويبات، الفلاتر، الجداول)
```
