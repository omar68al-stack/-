# لوحة القرار التنفيذية — جمعية إعمار المرافق

موقع لوحة تحكم تنفيذية لرئيس مجلس إدارة جمعية إعمار المرافق، لمتابعة الأداء التشغيلي واتخاذ القرار.

## المحتوى

- **نظرة عامة**: مؤشرات الأداء الرئيسية، تقدّم الأهداف الاستراتيجية، توزيع حالة المشاريع، والميزانية حسب الفئة.
- **المشاريع والمبادرات**: جدول زمني ربع سنوي وقائمة كاملة بالمشاريع مع فلاتر حسب الحالة.
- **مركز القرار**: القرارات المرفوعة لرئيس مجلس الإدارة، مع إمكانية الاعتماد/التأجيل/الرفض وإضافة ملاحظة على كل قرار.
- **المخاطر**: سجل مبسّط لأهم المخاطر ومستوى أثرها واحتمالية حدوثها.
- **عن الخطة التشغيلية**: الرؤية والرسالة، وملاحظة حول مصدر البيانات.

## تشغيل الموقع محليًا

الموقع ثابت بالكامل (HTML/CSS/JS بدون أي اعتماديات خارجية)، يكفي فتحه مباشرة أو تشغيل خادم بسيط:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## تحديث البيانات

كل بيانات اللوحة (المؤشرات، الأهداف، المشاريع، الميزانية، القرارات، المخاطر) موجودة في ملف واحد:

```
assets/js/data.js
```

القيم الحالية **بيانات تجريبية للعرض التوضيحي فقط**. لعرض الأرقام الفعلية:

1. افتح ملف الخطة التشغيلية (Google Sheets) وتأكد من مشاركته على الأقل بصلاحية "أي شخص لديه الرابط يمكنه العرض".
2. انسخ القيم الفعلية إلى الحقول المقابلة في `assets/js/data.js` (الأسماء والنسب والمبالغ وتواريخ الاستحقاق).
3. أعد تحميل الصفحة — لا حاجة لأي بناء (build) أو تثبيت حزم.

## مركز القرار — ملاحظة مهمة

القرارات (اعتماد/تأجيل/رفض) تُحفظ حاليًا في متصفح المستخدم فقط (`localStorage`)، أي أنها لا تُشارك تلقائيًا بين عدة أجهزة أو مستخدمين. إذا كان مطلوبًا أن يرى فريق العمل حالة القرار التي اعتمدها رئيس مجلس الإدارة من أجهزتهم، يلزم ربط الموقع بقاعدة بيانات/خادم خلفي بسيط (مثل Firebase أو أي واجهة API) بدلاً من التخزين المحلي.

## النشر

الموقع ثابت بالكامل، يمكن نشره فورًا على أي من:
- GitHub Pages
- Netlify / Vercel (سحب المجلد مباشرة)
- أي استضافة تدعم ملفات HTML ثابتة

## هيكل الملفات

```
index.html              الصفحة الرئيسية (كل الأقسام)
assets/css/style.css    التنسيق (فاتح/داكن)
assets/js/data.js       البيانات القابلة للتعديل
assets/js/charts.js     رسم المخططات (أشرطة، دونات، جدول زمني)
assets/js/app.js        منطق اللوحة (التنقل، الفلاتر، مركز القرار)
```
